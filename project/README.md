# Mission-Critical Project Application Directory

This directory (`project/`) is reserved exclusively for the output application synthesized by the 8-agent orchestration pipeline.

## Architectural Guidelines
1. **Isolated Workspace**: All application files, static assets, backend code, MDX content pages, and C bare-metal drivers reside here.
2. **Orchestration Control**: The project is maintained and updated dynamically by the orchestration scripts located in `../orchestration/`.
3. **Status**: Framework setup complete. Ready to ingest Product Requirement Document (PRD) for Phase 1 code synthesis.
