1. Why Karpathy-Wiki Leads in Code Generation for RTOS & Device Drivers

2. Building Highly Complicated RTOS & Device Driver Stacks

When building an RTOS Board Support Package (BSP) or writing a driver for a hard-real-time system, a developer does not simply need register descriptions—they need the hardware dependency graph:

  • Clock Gating: Which bit in RCC_AHB1ENR or RCC_APB2ENR must be asserted before the peripheral is clocked?
  • Interrupt Routing: Which vector position in the NVIC handles the peripheral's global IRQ?
  • Memory Mapping: What is the exact physical base address in the AHB/APB bus matrix?
  • Power Domain: Does the peripheral run in Low-Power Run (LPRUN) or Stop mode under PWR?

In ST's markdown, answering these four questions requires opening four separate 500 KB files and mentally correlating cross-references. In Karpathy-Wiki, every peripheral page (e.g. peripherals/dma.md) has a Dependencies & Interconnects section with direct, validated bidirectional links to system/rcc.md, core/nvic.md, and memory/memory_map.md.
